# Yo Cotizo Isapre

Base de la nueva aplicación personalizada para cotización de planes de Isapre.

## Portales incluidos

- Público: cotización, resultados, filtros y comparación sin acceso al PDF.
- Asesores: cotización profesional, documentos y herramientas de envío.
- Administración: planes, PDF, indicadores, asesores, leads y contenido.

## Desarrollo local

```bash
npm install
npm run dev
```

## Estado

Esta primera versión establece la arquitectura visual. Los datos demostrativos serán reemplazados por el importador de los 2.255 planes y el backend seguro para autenticación, cálculos, PDF y leads.
